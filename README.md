# Realidad Aumentada sin Marcadores (Markerless WebAR)

Aplicación Web de **Realidad Aumentada sin marcadores**, compatible con cualquier celular directamente desde el navegador web (Google Chrome, Safari, etc.).

---

## 🌟 Características Principales

1. **Sin marcadores impresos ni códigos QR**: No necesitas imprimir el marcador Hiro ni escanear ningún patrón físico; funciona directamente apuntando al entorno o a tu rostro.
2. **Cambio entre Cámaras (Frontal / Trasera)**:
   - 🔄 Botón en la esquina superior para alternar en tiempo real entre:
     - **Cámara Trasera (Mundo)**: Para proyectar figuras y personajes flotando en tu habitación, mesa o espacio.
     - **Cámara Frontal (Selfie)**: Modo espejo con filtros tipo redes sociales.
3. **Catálogo Completo Interactivo**:
   - 🔷 **Figuras 3D:** Hipercubo translúcido cuántico, Cristal Cósmico y Toroide Portal Neón con animaciones de rotación multi-eje y levitación.
   - 🤖 **Personajes 3D:**
     - **Robot CyberBot**: Con animación de flotación, saludo de brazos, ojos LED y núcleo brillante pulsante.
     - **Dron Explorador**: Con 4 rotores de alta velocidad girando en tiempo real, visor cibernético e inclinación física.
   - 🎭 **Filtros AR:**
     - **Lentes Cyberpunk**: Gafas de sol futuristas con pulso de color RGB dinámico.
     - **Corona Real**: Corona dorada con diamantes y rubíes flotando sobre la cabeza.
4. **Interacción Táctil Completa**:
   - **Girar:** Desliza 1 dedo para rotar la figura 360° en cualquier dirección.
   - **Zoom / Escala:** Pellizca con 2 dedos para agrandar o achicar el objeto.
   - 🧭 **Giroscopio (Opcional):** Botón para vincular la orientación física del celular con el mundo 3D.
